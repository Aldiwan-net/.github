<div align="center">

الديوان وُلد من رغبة حقيقية في حفظ الشعر العربي وإتاحته للجميع — من طالب يبحث عن بيت شعر، إلى مطوّر يبني تطبيقًا، إلى باحث يدرس اللغة والتراث.

*AlDiwan was born from a genuine desire to preserve Arabic poetry and make it accessible to everyone — from a student searching for a verse, to a developer building an app, to a researcher studying language and heritage.*

## 🚀 ابدأ البناء معنا · Start Building

```bash
# استكشف الـ API
curl https://api.aldiwan.net/v1/poems?limit=5

# أو استخدم الـ Flutter SDK

```
